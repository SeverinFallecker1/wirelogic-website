# WireLogic Website

Statische Produktwebsite für [wirelogicsystems.de](https://wirelogicsystems.de).

## Struktur

- `index.html`: Produkt-Landingpage
- `funktionen.html`: aktueller Funktionsumfang
- `roadmap.html`: Entwicklungsstand und Ausblick
- `support.html`: Beta, Feedback und freiwillige Unterstützung
- `privacy.html`: Datenschutzinformationen für Website und App
- `impressum.html`: Anbieterkennzeichnung
- `assets/css/main.css`: gemeinsames Designsystem
- `assets/js/site.js`: mobile Navigation, Reveal-Effekte und Jahreszahl

## Lokal ansehen

Die Dateien benötigen keinen Build-Schritt. Einen lokalen Webserver im
Repository starten und `index.html` im Browser öffnen.

## Vor Veröffentlichung

- Rechtstexte fachlich prüfen lassen.
- Fehlende Pflichtangaben im Impressum ergänzen, falls zutreffend.
- Aussagen zu App, Hosting und Drittanbietern gegen den aktuellen Stand prüfen.
- TestFlight-, WebViewer-, PayPal- und Social-Links testen.
- Keine Analyse-Skripte ohne passende Rechtsgrundlage und Aktualisierung der
  Datenschutzerklärung ergänzen.
